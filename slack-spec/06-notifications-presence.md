# Slack 完全再現仕様書 — 06. 通知 / プレゼンス / ステータス / DND

## 6.1 通知の判定パイプライン

新規メッセージが発生したとき、各受信ユーザーについて以下を順に評価して通知要否を決める:

```
1. ミュート判定: チャンネルがミュート? → mention 以外は通知しない
2. チャンネル通知設定:
     - all（すべてのメッセージ）
     - mentions（@mention とキーワードのみ） ← 既定（多くのチャンネル）
     - nothing（通知しない）
   DM/MPIM 既定は all
3. このメッセージは自分宛トリガを含むか:
     - <@self> 直接 mention
     - <!channel> / <!everyone>
     - <!here> かつ自分が active
     - 所属 <!subteam>
     - ハイライトワード（キーワード）一致
     - スレッド購読中の新着
4. DND 判定: DND/スヌーズ中? → プッシュ/音/バナーを抑制（バッジは更新）
5. 配信チャネル決定: デスクトップ / モバイルプッシュ / 音 / バッジ / メール
6. 重複抑制: 同一内容を複数端末で鳴らしすぎない（アクティブ端末優先）
```

---

## 6.2 通知設定（グローバル / per-channel / モバイル別）

### グローバル設定
- 通知タイミング: **すべてのメッセージ / ダイレクトメッセージ・mention・キーワード / なし**。
- **ハイライトワード（キーワード）**: 任意の語句リスト。一致でハイライト＋通知。
- スレッド返信通知: 参加スレッドの全返信を通知するか。
- 通知音・外観（バナー/プレビュー表示有無）。
- モバイルは別プロファイル（「デスクトップが非アクティブな時だけモバイル通知」＋遅延秒数設定）。
- 「自分の投稿へのリプライ/リアクション」通知トグル。
- メール通知（不在時のダイジェスト/未読メール）。

### per-channel 設定（上書き）
- all / mentions / nothing、ミュート、モバイル個別、スレッド通知。
- サイドバーのチャンネル右クリックから即変更。

### 通知スケジュール
- 「通知を受け取る時間帯」（営業時間）。時間外は DND と同様に抑制。曜日別可。

---

## 6.3 DND（Do Not Disturb）
- スケジュール DND（毎日 X時〜Y時、TZ 準拠）＋手動スヌーズ（30分/1時間/明日まで/カスタム）。
- DND 中: プッシュ/バナー/音を抑制。アプリ内バッジ・未読は更新。
- 送信者には相手 DND 表示（zzz アイコン）。「通知を無視して今すぐ知らせる」(notify anyway) 可。
- `dnd.info/setSnooze/endSnooze`。RTM `dnd_updated`/`dnd_updated_user`。

---

## 6.4 プレゼンス
- `active` / `away`（02 参照）。自動 away（無操作/切断）＋手動 away。
- アバターの緑●=active、白○=away。
- presence 購読は表示中ユーザー限定（スケール対策）。

---

## 6.5 カスタムステータス
- emoji + テキスト（最大100字）＋有効期限（30分/1時間/今日/今週/カスタム/無期限）。
- プリセット（会議中🗓️ / 通勤中🚌 / リモート🏠 / 病欠🤒 / 休暇中🌴 など。team でプリセット定義可）。
- ステータス絵文字はメッセージ横・メンバー一覧・プロフィールに表示。
- 期限切れで自動クリア。
- 連携: カレンダーアプリが「会議中」を自動セット、Huddle 参加中は自動でヘッドホン絵文字等。
- 「ステータス中は通知一時停止」連動オプション。

---

## 6.6 配信チャネル別実装

### デスクトップ通知
- OS ネイティブ通知（Electron/ブラウザ Notification API）。クリックで該当メッセージへジャンプ。
- プレビュー表示/非表示設定。バンドル（短時間に複数来たらまとめる）。

### モバイルプッシュ
- APNs（iOS）/ FCM（Android）。ペイロードは最小限（本文はサーバ取得 or 暗号化）。
- バッジ数 = 未読 mention/DM 合計。
- リッチプッシュ: 返信アクション、絵文字リアクション、既読化をプッシュから直接。

### メール通知
- 不在（全端末オフライン）かつ未読 mention/DM が残る場合、一定遅延後にメール。
- ダイジェスト（1日のまとめ）設定可。

### Slackbot
- システム通知・リマインダー・オンボーディング案内を Slackbot DM で届ける。

---

## 6.7 「すべて既読」「全社からの通知」管理
- ユーザー: 全チャンネル一括既読。
- 管理者: `@channel`/`@everyone` の使用権限を制限可（誤爆防止）。
