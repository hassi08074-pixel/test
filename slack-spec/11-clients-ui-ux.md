# Slack 完全再現仕様書 — 11. クライアント / UI / UX / ショートカット

## 11.1 クライアント種別
- **Web (SPA)**: ブラウザ。React 相当の SPA。
- **Desktop**: Electron（Web を内包＋ネイティブ通知/グローバルショートカット/複数ワークスペース/自動更新/ディープリンク `slack://`）。
- **Mobile**: iOS（Swift）/ Android（Kotlin）ネイティブ。プッシュ、オフラインキャッシュ、共有シート連携。
- すべて同一バックエンド（Web API + RTM）。

---

## 11.2 画面レイアウト（デスクトップ基準・厳密再現）

```
┌──────┬───────────────┬───────────────────────────┬──────────────┐
│ Rail │ Sidebar       │ Main message pane         │ Right pane   │
│(左端 │ (チャンネル/  │ (選択チャンネルの会話)    │ (スレッド/   │
│ ワーク│  DM/セクション)│                           │  プロフィール/│
│ スペー│               │  ヘッダ: 名前/トピック/    │  Canvas/詳細)│
│ ス&   │  上部: Home/  │   メンバー/通話/検索       │              │
│ 主要  │  DMs/Activity/│  本文: メッセージリスト    │              │
│ ナビ) │  Later/More   │  下部: コンポーザ          │              │
└──────┴───────────────┴───────────────────────────┴──────────────┘
```

### 左端レール（新ナビ）
- 複数ワークスペースのアイコン切替（未読バッジ付き）。
- 主要ビュー: **Home（チャンネル）/ DMs / Activity（通知履歴）/ Later（保存）/ More**。
- 一番下: アバター（presence/ステータス/設定）。

### サイドバー
- セクション: Starred / Channels / Direct Messages / Apps / カスタムセクション。
- フィルタ（未読/メンション）、並び順、折りたたみ。
- 行装飾: 太字（未読）、赤バッジ（mention 数）、鍵（private）、◇（外部共有）、ミュート減光。

### メインペイン
- ヘッダ: チャンネル名・トピック・メンバー数・★・通話/Huddle・Canvas タブ・ピン・検索・詳細。
- 本文: 日付区切り、連続投稿の集約（同一人の連投はアバター省略）、ホバーアクション、New 境界線、未読ジャンプ。
- 無限スクロール（上方向に過去ロード、下方向に新着）。
- コンポーザ（03 参照）。

### 右ペイン
- スレッド / プロフィール / チャンネル詳細 / Canvas / ファイル / ワークフロー / App Home を切替表示。

## 11.3 テーマ・外観
- ライト/ダーク/システム連動。サイドバーテーマ（色のプリセット＆カスタム配色）。
- アクセシビリティ: コントラスト、フォントサイズ、アニメーション低減、スクリーンリーダー対応（ARIA）、フルキーボード操作。
- 高密度/快適表示の切替。

## 11.4 キーボードショートカット（主要・完全再現対象）

| 操作 | Mac | Win/Linux |
|---|---|---|
| クイックスイッチャー（移動） | `⌘K` / `⌘T` | `Ctrl+K` |
| 検索 | `⌘G` / `⌘F` | `Ctrl+G/F` |
| 全ショートカット表示 | `⌘/` | `Ctrl+/` |
| 設定 | `⌘,` | `Ctrl+,` |
| 次/前の未読チャンネル | `Alt+Shift+↓/↑` | 同 |
| 次/前のチャンネル（履歴） | `⌘[` / `⌘]` | `Alt+←/→` |
| すべて既読 | `Shift+Esc` | 同 |
| チャンネルを既読 | `Esc` | 同 |
| 直前メッセージ編集 | `↑`（空コンポーザ） | 同 |
| 太字/斜体/取消/コード | `⌘B/⌘I/⌘Shift+X/⌘Shift+C` | `Ctrl+...` |
| ファイルアップロード | `⌘U` | `Ctrl+U` |
| 絵文字ピッカー | `⌘Shift+\` | 同 |
| スレッド/メッセージにリアクション | ホバー＋ショートカット | |
| ワークスペース切替 | `⌘1..9` | `Ctrl+1..9` |
| 太線の「未読へ移動」 | `⌘Shift+A`（All unread/Activity） | |

- メッセージリストフォーカス時の `j/k`（上下移動）、メッセージ選択後のアクションキー等も再現。

## 11.5 オンボーディング
- サインアップ（メール/SSO）→ ワークスペース作成 or 参加。
- ワークスペース作成ウィザード: 会社名、最初のチャンネル、招待メンバー、プロフィール、最初のメッセージ。
- 初回チュートリアル（Slackbot による対話ガイド、サンプルチャンネル `#random`/`#general`）。
- プロフィール補完、通知設定、アプリ導入の促し。

---

## 11.6 オフライン・パフォーマンス
- 起動時スナップショット（boot）＋差分（RTM）。
- メッセージ/ユーザー/絵文字をローカルキャッシュ（IndexedDB / SQLite）。
- 楽観 UI、遅延ロード（flannel）、画像遅延読込、仮想スクロール。
- 低速回線向けの段階ロード、再接続時の差分同期。

---

## 11.7 国際化
- UI 多言語（日本語含む数十言語）。
- ロケール別の日付/時刻/数値、TZ 表示（`<!date^...>` の受信側ローカライズ）。
- RTL 言語対応。絵文字スキントーンのデフォルト設定。

---

## 11.8 ディープリンク / 統合
- `slack://channel?team=T...&id=C...`、permalink `https://team.slack.com/archives/C.../p<ts>`。
- OS 共有シート、`mailto:`/カレンダー連携、ブラウザ拡張。
