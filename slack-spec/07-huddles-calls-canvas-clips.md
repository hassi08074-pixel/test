# Slack 完全再現仕様書 — 07. Huddle / 通話 / Canvas / Clip

## 7.1 Huddle（軽量音声/画面共有）

### 概念
- チャンネル/DM に紐づく**常設の軽量音声ルーム**。「ヘッドホンを付けて隣に座る」体験。会議招待不要、ワンクリック参加。

### 機能
- 音声（既定）、後からビデオ・画面共有を追加。
- チャンネルヘッダ/DM に Huddle 開始ボタン。参加中はチャンネルにバナー＋参加者アバター。
- 同チャンネルの他メンバーは「○人が Huddle 中」を見てワンクリック参加。
- 画面共有時に**共同描画（drawing）**・カーソル表示。
- Huddle 内**スレッド/メッセージ**: Huddle 専用のミニチャットに会話/リンク/絵文字。
- 退出後、Huddle のメッセージ履歴・共有リンクはチャンネルに残る。
- **文字起こし（transcription）**と要約（AI）に対応（プラン依存）。
- ライトウェイトな絵文字リアクション（手を挙げる🙋、👍をオーバーレイ）。

### 技術
- WebRTC（SFU 経由のメディアサーバ）。シグナリングは WS。
- 参加状態は presence と別系のリアルタイムルーム状態。`calls.*` API でメタを channel に表現。
- TURN/STUN、エコーキャンセル、ノイズ抑制。

## 7.2 通話 (Calls)
- 1:1 / グループの正式通話（Huddle より「会議」寄り）。
- ビデオ、画面共有、参加者管理。
- 外部通話プロバイダ統合（Zoom/Google Meet/Webex 等を `/zoom` 等のコマンドや Call ブロックで起動）。
- `calls.add/update/end` でチャンネルに通話カード（参加者・時間・join URL）を表示。
- 通話招待・呼び出し（着信 UI）。

## 7.3 Canvas

### 概念
- リッチドキュメント面。**チャンネル/DM に1つ紐づく channel canvas** と、**スタンドアロン canvas** がある。
- ナレッジ集約（オンボーディング資料、プロジェクト概要、議事録）。

### コンテンツモデル
- ブロックベースのリッチテキスト: 見出し、本文、箇条書き、番号付き、チェックリスト(ToDo)、引用、コードブロック、区切り線。
- 埋め込み: 画像/動画/ファイル、**Slack エンティティ参照**（@人、#チャンネル、メッセージ permalink）、テーブル、ボタン、外部リンクのリッチプレビュー。
- セクションごとの**アクセス制御**（特定の人だけ編集可など）。

### 共同編集
- リアルタイム同時編集（CRDT/OT）。カーソル・選択範囲・プレゼンス表示。
- コメント（テキスト選択に対するスレッドコメント）。
- バージョン履歴。

### 連携
- チャンネルヘッダに「Canvas」タブ。
- Canvas 内のチェックリスト項目に担当者(@)・期限を設定。
- 検索インデックス対象。

## 7.4 Clip（音声/動画メッセージ）
- コンポーザから録画する**短い音声/動画/画面録画**メッセージ。
- 非同期コミュニケーション（「会議の代わりに録画で共有」）。
- 自動**文字起こし**＆再生速度変更、サムネイル、シーク。
- ファイル(`mode` 動画/音声)として保存・共有・検索（文字起こしテキストが検索対象）。
- 視聴済み表示・視聴者数。
